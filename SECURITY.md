# Security Policy

## Supported Versions

This project is pre-1.0. Security fixes target the `main` branch until versioned releases are introduced.

## Reporting A Vulnerability

If you find a vulnerability, please avoid posting sensitive details in a public issue. Use GitHub private vulnerability reporting when available, or open a minimal issue that asks for a maintainer contact path without exposing exploit details.

## Public Data Boundary

This repository should not contain customer data, operator data, private rule libraries, logs, archives, spreadsheets, or proprietary solver internals. If you notice material that appears to violate that boundary, report it as a security issue.
